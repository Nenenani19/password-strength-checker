# 🔐 Password Strength Checker

## 📌 Description
A Java-based application that checks the strength of a password and provides suggestions to improve it.

## 🚀 Features
- Checks password length
- Detects uppercase and lowercase letters
- Verifies numbers and special characters
- Provides improvement suggestions

## 🛠️ Tech Used
- JavaScript
- CSS
- Java

## 🌐 Web Version
This project also includes a frontend interface using HTML, CSS, and JavaScript for real-time password analysis.
